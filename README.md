# analyse-discriminante-ADL-RStudio
Analyse Discriminante Linéaire

Nous allons réaliser une analyse discriminante linéaire. Le but de cette analyse est de construire un modèle qui permettra d’avoir la séparation la plus nette possible entre deux groupes d’individus grâce à des combinaisons linéaires de variables explicatives. Dans notre base de données les individus que l’on souhaite séparer sont ce qui ronflent et ceux qui ne ronflent pas avec à l’aide de leur âge, poids, taille, sexe, consommation en alcool et tabac.
